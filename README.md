# 探店美食地图 · 粉丝前台 + 博主管理面板

一个**纯静态、零服务器、零成本**的自媒体探店博主美食地图网页项目。

- **粉丝前台**（`index.html`，手机访问）：高德地图浏览探店店铺（双指缩放/拖动），点右上角切换城市/行政区；点「附近」定位后只看 **5 公里内**的店铺并按距离排序（定位结果已做 WGS-84→GCJ-02 纠偏，修掉约 500~700 米的系统偏差；电脑浏览器靠 WiFi/IP 定位误差仍偏大，手机上更准）；搜索店名、按**美食分类**筛选、按**距离/人均**排序、按**特色**（免费停车/可带宠物/无烟区）筛选；底部悬浮 Tab：**地图 / 收藏 / 博主**；点图钉或列表进入**店铺详情页**（视频**只展示封面，点击跳转 B站/小红书**观看、探店笔记/时间/人均/特色、**一键导航**唤起高德地图 App、复制店名兜底、收藏）；点博主进入**博主主页**（瀑布流视频卡片、封面显示人均+距离、最新/附近排序）。
- **博主管理面板**（`admin.html`，电脑使用）：可视化表单录入 / 编辑 / 删除店铺（含分类、人均、特色、博主、时间、封面、笔记），**导出 shops.js** 上传 GitHub 仓库即可完成更新。不需要登录、不需要后端、不需要数据库。
- **收藏**：粉丝点详情页/列表里的 ❤️ 收藏，存在手机浏览器（微信内置浏览器支持）的 localStorage 里，同设备刷新/重开不丢。

视觉风格：两套可爱风。
- 粉丝前台：奶油底 · 草莓粉 · 奶油黄，圆滚滚的食物 emoji 图钉 + 小店铺开门迎客动效。
- 博主后台：淡紫底 · 薰衣草紫 · 薄荷绿「探店小管家」仪表盘风（与前台刻意区分）。

## 一、目录结构

```
food-map/
├── index.html        ← 粉丝前台（地图浏览页，手机访问）
├── admin.html        ← 博主管理面板（电脑使用，本地表单）
├── config.js         ← ★ 唯一要手动改的文件：高德 Key + 标题
├── data/
│   └── shops.js      ← 店铺数据库（管理面板导出后替换这份）
├── preview.bat       ← Windows 双击本地预览（可选）
└── README.md
```

单条店铺数据格式（管理面板导出自动就是这个格式，包在 `window.SHOPS_DATA = [...]` 里）：

```js
window.SHOPS_DATA = [
  {
    "name": "某某美食店",
    "city": "厦门",
    "district": "湖里区",
    "lat": 24.51,
    "lng": 118.12,
    "category": "火锅",          // 美食分类（固定清单见 config.js 的 CATEGORIES：火锅/烧烤/海鲜/日料/西餐/自助餐/小吃快餐/咖啡/饮品/糕点烘焙/水果生鲜，图钉图标跟分类走）
    "price": 45,                // 人均（元，用于排序/展示）
    "features": ["parking", "pet"], // 特色：parking免费停车 / pet可带宠物 / nosmoke无烟区
    "blogger": "阿探",           // 博主名（同名的店聚合到同一博主主页）
    "date": "2026-10-20",       // 探店时间（"最新"排序依据）
    "videoUrl": "https://www.bilibili.com/video/BVxxxx/", // B站链接可页面内直接播放；小红书则跳转
    "cover": "",                // 封面图URL（选填，B站链接会自动抓封面）
    "note": "探店笔记…"         // 选填
  }
];
```

## 二、上线 4 步走（GitHub Pages 免费托管）

### 第 1 步：配置高德 Key

打开 `config.js`，把控制台里的 Key 填进去：

```js
AMAP_KEY: "你的高德Key",
SECURITY_JSCODE: "对应的安全密钥jscode（2021-12之后创建的Key必填，老Key留空）",
```

> Key 在 https://lbs.amap.com 控制台 → 应用管理 → 我的应用 里。
> 安全密钥（jscode）和 Key 在同一行展示，**2021年12月之后创建的 Key 必须一起填**，否则地图加载会被拒。
>
> ⚠️ **重要：账号必须完成「个人开发者认证」**。高德 2021 年后，未认证账号所有 API 月配额为 **0**（地图直接加载不出来）。
> 个人认证免费，在控制台 → 账号设置里提交即可；个人认证的免费额度（JS 地图 150 万次/月）对这种小项目完全够用，
> 用超了才会按量计费（详见 https://lbs.amap.com/pages/base_service_price ）。

### 第 2 步：创建 GitHub 仓库并上传

1. 登录 GitHub → 右上角 **+** → **New repository**，名字随意（例如 `food-map`），选 **Public**。
2. 在仓库页面点 **uploading an existing file**（或 Add file → Upload files），把 `index.html`、`admin.html`、`config.js`、`data/shops.json` 按**原目录结构**拖进去（可以先把整个 `food-map` 文件夹拖上去，GitHub 会保留结构）。
3. 点 **Commit changes**。

### 第 3 步：开启 GitHub Pages

1. 仓库页 → **Settings** → 左侧 **Pages**。
2. **Source** 选 `Deploy from a branch`，**Branch** 选 `main` / 目录选 `/ (root)` → Save。
3. 等 1~2 分钟，页面顶部会出现访问链接，形如：
   `https://你的用户名.github.io/food-map/`

**粉丝访问这个链接就是前台地图**；
**博主自己在电脑上访问** `https://你的用户名.github.io/food-map/admin.html` 就是管理面板。

### 第 4 步：日常更新店铺

1. 电脑打开 `admin.html` → 录入 / 编辑 / 删除店铺（数据自动暂存在浏览器里，关页面不丢）。
2. 点 **「📤 导出 shops.js」** 保存到本地。
3. 回到 GitHub 仓库 → `data/shops.js` → 点铅笔编辑，把导出文件内容整体粘贴替换（或 Add file 上传覆盖）→ Commit。
4. 粉丝刷新前台链接即可看到新店铺。

## 三、本地预览（可选）

- **方式 A（最省事）**：直接双击 `index.html` / `admin.html` 打开——数据走 `data/shops.js`（`<script>` 标签加载），双击也能正常显示店铺列表；地图需要联网加载高德脚本。
- **方式 B**：Windows 双击 `preview.bat`（需要装过 Python），浏览器会自动打开 `http://localhost:8088`：
  - 前台：`http://localhost:8088/index.html`
  - 后台：`http://localhost:8088/admin.html`
- **方式 C**：部署到 GitHub Pages 后看线上效果，最真实。

## 四、常见坑速查

| 现象 | 原因 / 解法 |
| --- | --- |
| 地图一片空白，占位提示"小店准备中" | `config.js` 里 Key 没填或填的还是占位文字 `你的高德Key` |
| 控制台报 `INVALID_USER_SCODE` | 2021-12 之后创建的 Key 没填 `SECURITY_JSCODE` |
| 前台开门面板显示"数据没上桌" | `data/shops.js` 文件缺失或格式不对；重新导出并确认上传位置是仓库的 `data/shops.js` |
| 更新了数据但前台没变化 | 确认上传替换的是仓库里 `data/shops.js`；浏览器缓存旧文件时按 Ctrl+Shift+R 硬刷新 |
| 高德 Key 报跨域/域名白名单错误 | 控制台里给这个 Key 的「域名白名单」留空（不限制），或加上 `你的用户名.github.io` |
| 换电脑/清了浏览器数据，管理面板数据没了 | 暂存只在本机浏览器里；换环境前先导出 shops.js，再用「导入」功能合并/覆盖进来 |

## 五、管理面板功能一览

- ✅ 表单录入：店铺名称、城市、行政区、纬度、经度、视频外链
- ✅ **地图选点**：在面板内嵌小地图上点一下，坐标自动填入（也可用高德坐标拾取器手动粘贴）
- ✅ 编辑 / 删除任意一条，删除有确认
- ✅ 列表搜索、总数 / 城市数 / 当前显示数统计
- ✅ **导出 shops.js**（标准格式，直接可上传仓库；双击本地打开前台也能读）
- ✅ **封面自动抓取**：填好 B站视频链接后点「🎬 抓封面」，自动把封面图填进来（小红书拿不到接口，手动粘贴封面图地址）
- ✅ **导入数据文件**：兼容 shops.js 和 shops.json，可选「合并导入」或「覆盖导入」，旧数据接着改不用重新录
- ✅ 数据实时暂存本浏览器（localStorage），关页面不丢
